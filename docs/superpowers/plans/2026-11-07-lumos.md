# Lumos Implementation Plan

> **For agentic workers:** Use executing-plans to implement tasks in this session.

**Goal:** 특수교육 허브와 두 교사용 앱을 구현하고 공개 배포 후 등록한다.
**Architecture:** Buildless ES modules, static output, Firebase Google Auth and per-user Firestore entries.
**Tech Stack:** HTML, CSS, JavaScript, Node test runner, Firebase Web SDK.
**Spec:** ../specs/2026-11-07-lumos-design.md

## Global Constraints
- 상대 경로, 모바일 및 키보드 접근, 실제 배포 확인 전 등록 금지.
- 사용자 데이터는 textContent로 렌더링. HTTPS 도구 URL만 허용.
- Firebase 계정과 프로젝트가 확인되기 전 외부 백엔드에 사용자 정보 쓰기 금지.

## Review Focus
- 손상된 localStorage는 기본값으로 복구.
- javascript URL, 자격증명 포함 URL은 거부.
- 로그아웃·계정 전환 시 일기와 편집 내용 즉시 비우기.
- 저장 실패는 성공으로 표시하지 않고 작성 내용 보존.
- 다른 계정·미인증 사용자의 일기 접근 차단.

- [ ] 2. index.html, app.mjs, styles.css에 허브·일정판·일기장 화면 구현. firebase-client.mjs에서 세션 인증과 CRUD 제공.
- [ ] 3. firestore.rules, firebase.json, firebase-config.js, 보안 규칙 테스트, README 및 보안 검토 문서 작성.
- [ ] 4. scripts/build.mjs, scripts/serve.mjs, Pages workflow 구현; 전체 테스트·빌드·브라우저 검증.
