# 루모스 특수교육 공방

사용자가 승인한 구성: 특수교육 프로그램을 모으는 허브, 로그인 없이 쓰는 시각 일정판, Google 로그인 기반 교사 개인 일기장.

## 방식
GitHub Pages에서 실행되는 HTML/CSS/ES modules와 Firebase Authentication + Cloud Firestore를 사용한다. 서버 렌더링은 필요 없으며 모든 페이지는 상대 경로로 프로젝트 Pages에서도 작동한다. 별도 서버 방식은 운영 부담이 있고 로컬 저장만 하는 일기장은 기기간 동기화를 제공하지 못하므로 채택하지 않는다.

## 화면
검은 밤하늘, 금빛 선, 고전적인 제목, 독자적으로 그린 마법 서재 문양을 사용한다. 기존 영화 로고나 이미지는 사용하지 않는다. 허브에는 검색, 분류, 즐겨찾기, 최근 도구와 프로젝트 추가 기능을 둔다. 사용자가 추가한 HTTPS 도구는 이 브라우저에 저장한다.

시각 일정판은 활동 추가·완료·순서 변경·삭제·초기화·인쇄를 지원한다. 교사가 수업 중 쓰기 쉬운 큰 카드와 명확한 현재 활동을 제공한다.

일기장은 날짜·제목·기분·본문을 계정별 비공개로 저장하고 수정·삭제·내보내기를 지원한다. Google 로그인은 세션 범위로 유지하고 공유 기기에서는 로그아웃한다. 로그인 전에는 본문 입력과 저장을 막는다. Firebase 미설정 상태에서는 연결 준비 중임을 사실대로 표시한다.

## 보안과 데이터
일정판·즐겨찾기·추가 도구만 localStorage에 저장한다. 일기 본문은 localStorage에 저장하지 않는다. 데이터 경로는 users/{uid}/entries/{id}; 소유자 확인, Google 제공자 확인, 필드 허용 목록·크기·타입·타임스탬프 검증을 적용한다. 공개 공유와 학생 개인정보 입력은 제공하지 않는다. 계정별 기록 삭제 및 JSON 내보내기를 제공한다. 별도 분석·광고·추적 코드를 넣지 않는다.

## 배포와 검증
Node 내장 테스트, 정적 파일 빌드, 브라우저 확인 및 Firebase emulator 보안 규칙 테스트를 가능한 범위에서 진행한다. GitHub와 Firebase 인증이 확인되면 실제 프로젝트를 생성·배포한다. 제3자의 등록 Firebase는 앱 백엔드로 재사용하지 않는다. 공개 URL을 확인한 뒤 안내의 공개 HTTP 등록 클라이언트를 검토하고 실행한다. 배포 또는 인증이 막히면 완료로 보고하지 않는다.
